**C++ desktop robot · code on Gitee**

A desktop robot written in C++, built around three ideas:

- **Model calls** — the robot's behavior is driven by calls to language models rather than a fixed script.
- **Emoji and visual expression** — part of what the robot communicates is expressed through emoji and visuals.
- **Personalized actions** — actions can be individualized.

Code: [gitee.com/qian-chen-qian/sme208_desk_robot](https://gitee.com/qian-chen-qian/sme208_desk_robot)
